# Changelog

## 1.0.0 - 2026-05-04

Initial public release of the Otalan mobile OTA SDK packages.

### Added

- Added `@otalan/capacitor` for Capacitor OTA checks, bundle download and staging, reloads, and install confirmation.
- Added `@otalan/expo` for Expo and bare React Native startup confirmation with `expo-updates`.
- Added transfer source reporting for downloaded and cached Capacitor bundles.
- Added authenticated Expo asset request documentation.
- Added package support ranges for Capacitor 7 and 8, Expo SDK 54 and 55, and supported bare React Native versions.

### Changed

- Expanded Capacitor peer dependency ranges to cover Capacitor 7 and 8.
- Expanded Expo peer dependency ranges to cover supported Expo SDK and bare React Native combinations.
